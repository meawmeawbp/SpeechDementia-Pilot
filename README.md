# SpeechDementia-Pilot

เว็บเก็บข้อมูลเสียงพูดช่วงทดลองระบบ ของโครงการ “การคัดกรองภาวะสมองเสื่อมในผู้สูงอายุด้วยปัญญาประดิษฐ์จากการวิเคราะห์ข้อมูลเสียงพูดและคุณลักษณะทางภาษา”

- ผู้จัดทำ: บุญฐิตา พรรณกุล นักศึกษา CEDT คณะวิศวกรรมศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย
- สถานะ: ช่วงทดลองระบบ ยังไม่ได้รับการรับรองจากคณะกรรมการจริยธรรมการวิจัยในมนุษย์
- ระบบนี้ไม่วินิจฉัยโรคและไม่แสดงผลประเมิน

ไฟล์
- `index.html` หน้าเว็บทั้งหมด (เปิดผ่าน GitHub Pages)
- `apps_script_Code.gs` โค้ดฝั่ง Google Apps Script ที่รับข้อมูลและเก็บลง Google Drive ของผู้จัดทำ

repo นี้ไม่มีข้อมูลผู้เข้าร่วมใด ๆ ข้อมูลทั้งหมดเก็บใน Google Drive ที่จำกัดสิทธิ์
